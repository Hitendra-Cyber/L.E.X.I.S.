# Security Policy

## Supported Disclosure

If you discover a vulnerability in this project, do not open a public issue with exploit details.

Please report it privately through the appropriate GitHub security advisory workflow or by contacting the repository maintainer directly.

## Safe Publishing Checklist

- Keep secrets out of the repository.
- Verify `.gitignore` is present before first commit.
- Do not commit local caches, build outputs, or `.venv/`.
- Review synthetic or sample data for accidental inclusion of sensitive real-world data.
